## How to Add New Languages

1. Create new locale directory: `locale/<lang_code>/LC_MESSAGES/`
2. Run `python manage.py makemessages -l <lang_code>`
3. Translate the .po file
4. Run `python manage.py compilemessages`

## How to Use Translations

### In Python Code
```python
from django.utils.translation import gettext_lazy as _

class MyView(APIView):
    def get(self, request):
        return Response({"detail": _("Success message")})
```

### In Templates
```html
{% load i18n %}
{% trans "Success message" %}
```

### In Serializers
```python
from django.utils.translation import gettext_lazy as _

class MySerializer(serializers.Serializer):
    def validate(self, data):
        if not data:
            raise serializers.ValidationError(_("This field is required."))
```

## How to Compile Translations

```bash

source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

# Compile all translation files
python manage.py makemessages --all
python manage.py compilemessages
```
